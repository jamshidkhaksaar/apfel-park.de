# Stitch Design Prompt: Apfel Park - Dark Luxury Redesign

## 1. Aesthetic & Vibe (The "European Luxury" Look)
Create a **premium, high-contrast, dark-mode** interface that embodies a "Modern European Tech Atelier" aesthetic.
*   **Color Palette:** Deep matte black backgrounds (`#0b0b0c`) accented with sophisticated metallic gold (`#d49e42`) and muted platinum.
*   **Typography:** Use a high-contrast **Serif font** (like *Playfair Display* or *Cinzel*) for all major headings to create an editorial, luxury magazine feel. Keep body text in a clean, legible Sans-Serif (`Inter` or `Geist`) for technical clarity.
*   **Atmosphere:** Minimalist, spacious, and precise. Avoid clutter. Use subtle lighting effects to create depth.

## 2. Structural Layout Changes

### Hero Section: The "Mesh" Atmosphere
*   **Background:** Replace the solid dark background with a **subtle, slow-moving mesh gradient**. Blend deep charcoal, midnight blue, and faint gold light to create a "living" atmosphere behind the main content.
*   **Headline:** Center the main value proposition ("Smart Phone. Smart Service.") using the new Serif font. Make it large and commanding.

### Services Section: The "Bento" Grid
*   **Transformation:** Convert the standard uniform grid of services ("Display", "Water Damage", "Chip Repair") into a **Bento Grid** layout.
*   **Layout Details:** Use cards of varying sizes (e.g., one large square for the most popular service, flanked by smaller rectangular cards).
*   **Card Style:** Use **Glassmorphism**. Dark, semi-transparent frosted glass backgrounds with thin, faint white borders. On hover, the border should glow gold.

## 3. Micro-Interactions & Polish
*   **Buttons:** Make all primary Call-to-Action buttons (e.g., "Reparatur starten") pill-shaped with a **magnetic hover effect** (button slightly follows the cursor) and a subtle inner gold glow.
*   **Images:** Apply a "soft glow" shadow behind product images (Smartphones, Laptops) to make them pop off the dark background.

## 4. Execution Step-by-Step
1.  **Apply Theme:** First, establish the dark background and Serif/Sans-Serif font pairing.
2.  **Build Layout:** Construct the Hero Mesh Gradient and the Services Bento Grid.
3.  **Refine UI:** Apply the glassmorphism and gold hover states to all cards and buttons.
